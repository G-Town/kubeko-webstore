## Collections page

- Shows only the collections selected in the theme editor, in their arranged order.
- Removed the non-working previous/next and page-number controls.
- Cards respond to screen size: one per row on phones, two on tablets, three on desktops.
- Incomplete rows are centered; the current two collections appear as a centered pair.
- Cards use the collection image, or the first product image if the collection has none.
- Collections with no image use a plain charcoal panel and no “no image” message.
- A collection’s optional second image appears on hover on mouse or trackpad devices; touch devices keep the first image.
- Renamed the section to “Curated Collections” in the theme editor.

## Theme fixes

- Restored the collection links on product pages.
- Fixed the homepage hero image and made the hero always appear.
- Product card images now reserve their space while loading.
- Removed the unused full-page “look” view; looks still open in the collection-page modal.
- Removed an invalid setting from the collection page’s product section.

## Choices you can change

- **Centered two-card layout** — currently a centered pair; can start from the left instead.
- **Centered partial rows** — incomplete rows currently center; can start from the left instead.
- **Portrait card shape** — currently slightly taller than wide; can be square or landscape.
- **Hover image** — currently optional and hover-only; can remove it, always show the first image, or use a different image.
- **No-image panel** — currently plain charcoal; can use another color or a short message.
- **Title bar** — currently a light translucent bar at the bottom; can change the bar, text size, or placement.
- **Section name** — currently “Curated Collections”; can use a different label.
- **Card spacing and maximum width** — can be increased or decreased.
